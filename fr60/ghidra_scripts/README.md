# Java source directory to hold module-specific Ghidra scripts.

## ExportDecompiled
Postscript for analyzeHeadless flow. Dumps dissassembler output, generated p-code, and the decompiled pseudocode into the `tests/output` directory.

## ImportMmio
Prescript for analyzeHeadless flow. Defines memory blocks and labels for a given MMIO map, imports this info into ghidra project.
